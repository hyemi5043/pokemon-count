# Pokémon Court: 정의의 여정 (Hybrid Pixel RPG)

픽셀 탐험 맵과 비주얼노벨형 법정 장면을 결합한 브라우저 게임 프로토타입입니다.

## 파일 구성
- `index.html` — 게임 화면 구조
- `style.css` — 픽셀풍 UI, 탐험/법정 레이아웃 및 반응형 스타일
- `game.js` — 판사 선택, 30개 구역/225개 사건, 탐험, 증거 수집, 증언 심리, 판결, 성장, 동료 관리, 저장

## 실행 방법
1. ZIP 압축을 풉니다.
2. `index.html`, `style.css`, `game.js`가 같은 폴더에 있는지 확인합니다.
3. `index.html`을 Chrome 또는 Edge에서 엽니다.
4. 새 게임 시작 → 판사 포켓몬 선택 → 판사 임명 순서로 진행합니다.

별도 설치나 서버는 필요하지 않습니다. 폰트는 인터넷 연결이 있을 때 Google Fonts를 사용하며, 오프라인에서는 기본 글꼴로 대체됩니다.

## 플레이 방법
### 탐험/수사
- WASD 또는 방향키: 캐릭터 이동
- E: 가까운 조사 지점 또는 목격자와 상호작용
- 맵의 반짝이는 지점을 마우스로 클릭하거나 오른쪽 현장 수첩의 조사 버튼을 눌러도 조사할 수 있습니다.
- 모든 증거를 모으고 목격자와 대화하면 법정으로 이동할 수 있습니다.

### 법정
- 증언의 진술 하나를 선택합니다.
- 해당 진술의 모순을 입증할 증거 하나를 선택합니다.
- 두 선택이 모두 맞으면 다음 심리로 넘어갑니다.
- 모든 심리를 마치면 유죄/무죄/증거 불충분 중 판결을 선택합니다.
- 잘못된 판결은 사건 완료로 처리되지 않으며 다시 도전할 수 있습니다.

### 성장/파티
- 올바른 판결을 내리면 판사 경험치와 JP를 얻습니다.
- 판사 등급은 견습 → 초급 → 중급 → 상급 → 전문 → 베테랑 순서입니다.
- 올바르게 유죄 판결한 사건 중 교화 대상인 피고는 동료가 되기를 권유할 수 있습니다.
- 파티는 판사 1마리 + 동료 최대 3마리(총 4마리)입니다.
- 동료는 사건을 성공적으로 해결할 때 경험치를 얻습니다.

## 콘텐츠 규모
- 30개 스테이지
- 스테이지별 재판 수: 5, 6, 7, 8, 9, 10회 (각 5개 스테이지씩)
- 총 225개 사건 슬롯
- 스테이지 후반으로 갈수록 증거 수와 법정 심리 횟수가 증가합니다.

## GitHub Pages 배포
1. 저장소 최상위(root)에 `index.html`, `style.css`, `game.js`를 업로드합니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. Branch `main`, Folder `/(root)`로 설정하고 저장합니다.
4. 배포 주소를 열어 플레이합니다.

## 저장 데이터
- 브라우저 `localStorage`에 저장됩니다.
- 같은 브라우저/기기에서 이어하기가 가능합니다.
- 저장 키: `pokemonCourtHybrid_v3_save`
- 새 게임을 시작하면 현재 저장 데이터가 초기화되므로 확인창을 읽고 진행하세요.

## 프로토타입 범위 및 제한
- 이 버전은 혼합형 게임의 실제 플레이 루프를 확인하는 싱글플레이 프로토타입입니다.
- 225개 사건 슬롯은 데이터 생성 규칙으로 구성되어 있으며, 각 사건의 장편 고유 스토리/전용 픽셀 맵/전용 대화가 모두 수작업으로 완성된 상용 게임 수준은 아닙니다.
- 온라인 멀티플레이, 계정 동기화, 실제 포켓몬 스프라이트/음원은 포함하지 않습니다.
- 픽셀 맵은 Canvas 도형으로 생성하며, 법정은 픽셀풍 CSS 장면으로 표현합니다.
- 포켓몬 IP와 캐릭터의 권리는 각 권리자에게 있습니다. 비공식 팬메이드 프로젝트입니다.
