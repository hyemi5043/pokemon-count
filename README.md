# Pokémon Court: 정의의 여정 (Hybrid Prototype)

## 실행
1. ZIP 압축을 풉니다.
2. `pokemon_court_hybrid_v3` 폴더 안의 `index.html`, `style.css`, `game.js`가 함께 있는지 확인합니다.
3. `index.html`을 Chrome 또는 Edge에서 엽니다.
4. 새 재판 시작 → 판사 포켓몬 선택 → 판사 임명 → 제1구역 → 사건 시작 순서로 진행합니다.

## 조작
- 탐험 이동: WASD 또는 방향키
- 조사: E 키
- 마우스로 지도 타일을 클릭해 이동/조사 지점에 접근할 수도 있습니다.
- 현장 증거를 3개 이상 모으면 법정으로 이동할 수 있습니다.
- 법정에서 모순 진술과 증거를 각각 선택하고 `이의 제기 · 증거 제시`를 누릅니다.

## GitHub Pages 배포
저장소 최상위(root)에 `index.html`, `style.css`, `game.js`를 업로드합니다. 폴더 구조를 바꾸지 말고 세 파일을 같은 위치에 둡니다. Settings → Pages → Deploy from a branch → main → /(root)로 설정합니다.

## 현재 프로토타입 범위
- 판사 후보 선택, 판사 등급/경험치, 30개 스테이지 목록
- 스테이지별 5~10개 사건 슬롯(총 225개)
- 타일형 픽셀 탐험 캔버스, 키보드 이동, 조사 지점 및 증거 수집
- 증언 선택, 증거 제출, 집중력, 판결 보상
- 동료 영입 및 4마리 파티 관리
- LocalStorage 자동 저장 및 수동 저장

참고: 225개 슬롯은 확장 가능한 프로토타입 데이터 구조이며, 모든 사건의 개별 시나리오/전용 맵/분기 스토리가 완성된 상용 게임 수준은 아닙니다. 그래픽은 임시 픽셀 캔버스와 문자 스프라이트를 사용합니다. 온라인 멀티플레이는 포함하지 않습니다.
