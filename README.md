# 별빛 재판소 — 포켓몬 법정기록
브라우저 실행형 픽셀풍 팬메이드 프로토타입입니다.

## 실행
압축 해제 후 `index.html`을 Chrome/Edge에서 엽니다. 별도 설치나 서버 없이 플레이할 수 있습니다.

## 조작
- 방향키 또는 WASD: 현장 이동
- E 또는 조사하기 버튼: 근처 물음표 조사
- 모바일: 화면 방향 버튼

## 포함
- 30개 구역 × 5개 사건 레코드 = 150건
- 현장 조사, 단서 수집, 증인 진술, 증거 제시, 판결
- 판사 평판/등급, 교화 동료 최대 4마리, 브라우저 자동 저장
- 직접 제작한 구역별 픽셀 배경 30종, 오리지널 마스코트 12종 및 4방향 걷기 스프라이트

## 이동 및 배경 개선\n- 30개 구역마다 서로 다른 테마 배경을 적용했습니다.\n- 플레이어 캐릭터는 상하좌우 방향을 바라보며 4프레임 걷기 모션으로 이동합니다.\n\n## 한계
150건은 5개 사건 골격을 지역·등장인물에 맞춰 변주한 데이터입니다. 사건마다 독립된 스토리/퍼즐 150개가 완성된 것은 아닙니다. 전투, 사운드, 온라인 멀티플레이, 공식 포켓몬 아트워크는 포함되지 않습니다. 공식/상업용 게임이 아닌 팬메이드 프로토타입입니다.

## GitHub Pages
저장소 최상위에 `index.html`, `style.css`, `game.js`, `assets/`를 올리고 Settings → Pages → Deploy from a branch → main / root를 선택하세요.
