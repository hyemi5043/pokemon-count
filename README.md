# Pokémon Court (포켓몬 재판소)

브라우저에서 실행하는 포켓몬 팬게임 프로토타입입니다.

## 실행 방법
1. ZIP 압축을 풉니다.
2. `index.html`을 더블클릭하거나 VS Code에서 Live Server로 실행합니다.
3. 메인 화면에서 `혼자 재판하기`를 선택합니다.

## 현재 구현된 기능
- 첫 번째 사건: 사라진 이상해씨의 씨앗
- 증인 진술 선택
- 증거 카드 선택 및 제출
- 진술과 증거의 모순 판정
- 심리 진행 및 결과 화면
- 모바일 화면 대응

## 아직 구현되지 않은 기능
- 실제 인터넷 온라인 멀티플레이
- 계정 및 클라우드 저장
- 사건 편집기와 사건 랜덤 생성
- AI가 자유롭게 반박하는 대화 시스템

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`, `style.css`, `game.js`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Deploy from a branch를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 Save를 누릅니다.
6. 잠시 기다리면 생성된 Pages 주소로 접속할 수 있습니다.

## 온라인 멀티플레이 안내
GitHub Pages는 정적 웹사이트 호스팅이므로 그 자체로 실시간 방/동기화를 제공하지 않습니다.
친구와 각자 접속하는 온라인 재판은 다음 단계에서 Supabase Realtime 또는 별도 Node.js 서버를 연결해야 합니다.
