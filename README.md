# POKÉMON COURT — The Journey of Justice

웹 브라우저에서 실행하는 픽셀 어드벤처 + 추리 법정 RPG 프로토타입입니다.

## 실행
1. ZIP을 압축 해제합니다.
2. `pokemon_court_web_ultimate` 폴더 안의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. 첫 판사 포켓몬을 선택하고 여정을 시작합니다.

인터넷 연결이 필요합니다. 포켓몬 공식 일러스트/스프라이트는 PokeAPI의 공개 스프라이트 저장소에서 불러오며, 폰트는 Google Fonts를 사용합니다.

## 조작
- 이동: `W A S D` 또는 방향키
- 조사: `E` 또는 스페이스
- 모바일: 화면 아래 방향 버튼과 조사 버튼
- 지도에서 가까운 타일 클릭: 해당 위치로 이동/조사 시도

## 포함 기능
- 판사 포켓몬 선택
- 30개 법정 구역, 구역별 5개 사건 데이터
- 필드 탐험 및 단서 3개 수집
- 진술/증거 조합을 이용한 법정 심리
- 판사 레벨, 경험치, JP 보상
- 교화 동료 영입 및 4마리 파티 편성
- 브라우저 로컬 저장 및 이어하기
- PC/모바일 반응형 UI

## 프로젝트 구조
- `index.html`: 화면 구조
- `style.css`: 반응형 UI 및 화면 연출
- `game.js`: 게임 데이터, 탐험, 법정, 성장/저장 로직

## GitHub Pages 배포
1. 저장소 최상위에 `index.html`, `style.css`, `game.js`, `README.md`를 올립니다.
2. GitHub 저장소 Settings → Pages에서 배포 브랜치와 `/ (root)`를 선택합니다.
3. 생성된 Pages 주소로 접속합니다.

## 알려진 제한
- 현재 버전은 싱글 플레이 웹게임입니다. 온라인 멀티플레이는 포함하지 않습니다.
- 포켓몬 이미지는 외부 저장소에서 불러오므로 네트워크가 없거나 원본 서버가 응답하지 않으면 이미지가 표시되지 않을 수 있습니다.
- 현재 사건은 30개 구역의 진행 구조를 갖춘 플레이 가능한 데모 콘텐츠입니다. 각 사건의 고유한 장편 대사/스토리, 컷신, 오디오, 밸런스는 정식 공개 전 추가 제작·검수가 필요합니다.
- 비공식 팬 프로젝트이며 Nintendo, Game Freak, The Pokémon Company와 제휴·승인된 작품이 아닙니다. 공개 배포 전 이미지·음악·상표 등 권리 및 팬 콘텐츠 정책을 확인해야 합니다.
