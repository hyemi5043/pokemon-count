# Pokémon Court Academy · 정의의 저울

브라우저에서 실행하는 포켓몬 법정 육성 게임 프로토타입입니다.

## 파일 구성
- `index.html`: 게임 화면 구조
- `style.css`: 법정 테마 UI 및 반응형 레이아웃
- `game.js`: 판사 선택, 30개 구역/225개 사건, 증언·증거 심리, 경험치·등급·동료 영입 및 저장

## 로컬 실행
1. 이 폴더의 파일 3개(index.html, style.css, game.js)를 같은 위치에 둡니다.
2. `index.html`을 크롬 또는 엣지에서 엽니다.
3. 시작 화면에서 판사 포켓몬을 선택합니다.

## GitHub Pages 배포
1. GitHub 저장소 최상위(root)에 위 3개 파일을 업로드합니다. 폴더 안에 한 번 더 넣지 마세요.
2. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
3. Branch `main`, Folder `/(root)`로 설정하고 저장합니다.
4. 배포된 `https://계정명.github.io/저장소명/` 주소로 접속합니다.

## 게임 진행
- 판사 포켓몬 12종 중 하나를 선택합니다.
- 총 30개 구역, 구역당 5~10건으로 총 225건의 재판이 있습니다.
- 사건별 심리는 구역에 따라 2~5회로 증가합니다.
- 각 심리에서 모순되는 진술과 결정적 증거를 함께 선택해야 합니다.
- 재판 성공 시 경험치와 JP를 얻고 판사 레벨/등급이 오릅니다.
- 피고 포켓몬은 교화 동료로 영입되며 동료 경험치도 쌓입니다. 엔트리는 최대 6마리입니다.
- 진행도는 브라우저 localStorage에 저장됩니다. 같은 브라우저/기기에서 이어하기가 가능합니다.

## 참고
비공식 팬메이드 프로토타입입니다. 포켓몬 관련 상표·캐릭터 권리는 각 권리자에게 있습니다. 온라인 멀티플레이와 계정 간 저장 동기화는 포함하지 않습니다.
