# 포켓몬 재판소: 글리치 법정 (Pokémon Court)

GitHub Pages 배포 및 로컬 실행이 가능한 Single-file 웹 기반 포켓몬 추리 RPG 게임입니다.

## 📌 주요 특징 및 기능
- **30개 구역 & 150건의 사건 데이터**: 구역 탐험 및 각 사건에 따른 조사/재판 진행
- **픽셀풍 타일맵 & 마스코트**: 6가지 픽셀 컬러 팔레트 타일맵 배경 및 12종 오리지널 마스코트
- **현장 조사 & 재판 시스템**: WASD/방향키 이동, 단서 수집, 이의 있음! 연출, 증거 제시 및 최종 판결
- **판사 평판 & 교화 파티**: 판결 결과에 따른 평판 등급(S급, SS급 등) 및 최대 4마리 파티 영입
- **자동 저장**: LocalStorage를 이용한 브라우저 자동 저장

## 🚀 실행 및 배포 방법
1. **로컬 실행**: `index.html` 파일을 브라우저로 직접 열거나 VS Code Live Server로 실행합니다.
2. **GitHub Pages 배포**:
   - 이 압축 파일의 해제 후 생성된 `index.html`과 `README.md`를 깃허브 저장소(Repository) root에 업로드합니다.
   - `Settings` -> `Pages`에서 Source Branch를 `main` (또는 `master`)으로 선택하고 저장합니다.
