# Pokémon Court: The Judge's Path

포켓몬 판사를 선택해 재판을 해결하고, 경험치를 얻어 판사 등급을 올리며, 교화한 포켓몬을 동료로 영입하는 브라우저 팬게임 프로토타입입니다.

## 실행 방법
1. ZIP을 압축 해제합니다.
2. `index.html`, `style.css`, `game.js`, `README.md`가 같은 폴더에 있는지 확인합니다.
3. `index.html`을 더블클릭하거나 VS Code의 Live Server로 실행합니다.
4. `판사 임명하기`를 눌러 판사 포켓몬을 선택합니다.

## 게임 구성
- 판사 포켓몬 12종 중 1종 선택
- 30개 스테이지, 총 225개 재판
- 스테이지별 재판 수: 5건부터 시작해 5개 스테이지마다 1건씩 증가 (최대 10건)
- 후반 스테이지는 심리 횟수와 진술 선택지, 증거 카드 수가 증가
- 견습 → 초급 → 중급 → 상급 → 전문 → 베테랑 판사 등급
- 재판 성공 시 경험치 획득 및 피고 포켓몬 영입
- 영입한 동료 포켓몬도 재판 보상 경험치로 성장
- 브라우저 localStorage에 진행 상황 자동 저장

## GitHub Pages 배포
1. GitHub에서 새 Repository를 생성합니다.
2. `index.html`, `style.css`, `game.js`, `README.md` 네 파일을 저장소 최상위(root)에 업로드합니다. 폴더 안에 한 번 더 넣지 마세요.
3. 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 Save를 누릅니다.
6. Pages가 발급한 주소로 접속합니다.

## 저장 데이터
진행도는 현재 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지는 않습니다. 브라우저 데이터를 삭제하면 진행도도 사라질 수 있습니다.

## 현재 버전의 범위
- 사건은 게임 내 규칙에 따라 조합되는 싱글플레이 재판입니다.
- 실제 온라인 멀티플레이, 계정 로그인, 서버 저장, 공식 포켓몬 이미지/도감 API 연동은 포함하지 않았습니다.
- 포켓몬 이름과 소재를 활용한 비공식 팬 프로젝트이며 공식 게임이 아닙니다.
